# 真心话功能实施计划

## Context（为什么做）

用户要在现有「大冒险」之外新增并列玩法「真心话」，先上线「一男一女」题库（`truth-bank.json` 已人工审核入库，118 题），「普通（多男多女）」题库预留、内容后续再加。要求：

- 入口形态与「大冒险」一致：**首页按钮 + 独立路由**（底部导航不动）。
- **复用现有视觉组件，只新建真心话专属路由与逻辑**（不做一套新 UI，避免复杂化）。
- 设置项**只保留语言（中/英/双语）**，不加盾牌、无计时（题库 `timerSec` 全为 null）。

目标产物：从首页点「真心话」→ 选题库/语言 → 进入题库按五档出题，支持语言切换与「下一个/换一个」，普通题库显示空态占位。

## 内容层

- 新增 `content/truth/pair.ts`：把 `truth-bank.json` 的 118 题一次性转换为运行时 `Challenge[]`，每题为 `{ id, level, zh, en, contentTags: [], timerSeconds: null }`，满足 `lib/punishment/schema.ts` 的 `.strict()`。保留原始 id（`TR-L{n}-xxx`）。
  - 按导入说明：不映射盾牌标签（`contentTags` 全空）、本包无计时、不改写已审核题面。
- 新增 `content/truth/normal.ts`：普通题库占位，导出空 `Challenge[]`（后续补内容）。
- 题库包内 `truth-bank.json` / `truth-bank.schema.json` / `review.csv` 保持原样，仅作追溯真源，不进运行时。

## 逻辑层（尽量复用）

- 复用：`lib/punishment/schema.ts`（`Challenge`/`Level`/`sessionSchema`）、`lib/punishment/deck.ts`（`drawCard`）、`lib/punishment/filter.ts`、`lib/punishment/loadChallenges.ts`。
- 新增 `lib/truth/storage.ts`：真心话**独立**的偏好与进度存储，避免与大冒险串数据：
  - `TRUTH_PREFERENCES_KEY = "party-night-truth-preferences-v1"`，schema `{ language, bank }`（`bank: "pair" | "normal"`，默认 `pair`）。
  - `TRUTH_SESSION_KEY = "party-night-truth-session-v1"`，复用 `sessionSchema` 形状，提供 `newSession/readSession/saveSession`。

## 组件层（复用现有视觉，不新增 CSS）

- 直接复用：`ChallengeCard`（`timing` 恒 `false`）、`LevelDots`、`ActionBar`（`seconds=null`/`status="idle"` 时自动只显示「下一个 / 换一个」）、`EmptyPoolState`、`Modal`、`Button`、`LanguageChoices`。
- 新增 `components/truth/BankChoices.tsx`：真心话题库选择（「一男一女」= `pair`、「普通」= `normal`，普通显示为「即将上线」置灰不可选）。

## 路由层

- 新增 `app/truth/page.tsx`（设置页，照 `app/punishment/page.tsx` 精简）：题库 + 语言 + 「开始」→ `/truth/play`。**无盾牌**。
- 新增 `app/truth/play/page.tsx`（游戏页，照 `app/punishment/play/page.tsx` 精简）：
  - header：返回链接、五档 `LevelDots`、语言按钮（弹 `Modal` 用 `LanguageChoices`）。
  - 题卡：`ChallengeCard`（无 `TimerOverlay`、无计时逻辑）。
  - footer：`ActionBar`（仅「下一个 / 换一个」）。
  - 空池（普通题库为空）→ `EmptyPoolState`（提供「切换其他档 / 去设置」）。
- 首页 `app/page.tsx`：在「大冒险」下新增 `.home-primary`「真心话」→ `/truth`（相邻间距规则 `.home-primary + .home-primary` 已存在）。

## 入口 / 导航

- 底部导航 `components/ui/BottomTabBar.tsx` **不改**（用户选首页按钮形态）。

## 测试

- 新增 `tests/unit/truth.test.ts`：118 题、五档隔离（各档题量 44/25/16/11/22）、`timerSeconds` 全 `null`、`loadChallenges` 通过、`drawCard` 不重复且不连续重复、普通题库为空。
- 新增 `tests/e2e/truth.spec.ts`（照 `tests/e2e/punishment.spec.ts` 精简）：首页点「真心话」→ `/truth` → 开始 → `/truth/play`；切档立即换到该档题；切英文只显 `[lang=en]`；「下一个/换一个」可用；**不出现计时按钮**；普通题库空态可见。

## 验证

1. `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm test:e2e` 通过。
2. `pnpm build:export` 静态导出通过。
3. 可选真机：`pnpm android:release` → `./gradlew assembleDebug` → 装到 note12tpro 目视核对（用户未要求则不自动做）。

## 边界与不做

- 不动「大冒险」现有代码与产品冻结样式；不加盾牌、不加计时、不新增角色/治理流程。
- 未经授权**不 commit / 不 push**。
