# 谁最可能 · 重做设计稿（吃瓜版，过稿用）

> 状态：设计稿，未落地。**现役谁最可能 50 题 / `v2-ssot` 一律不改**，本稿只描述"应该长成什么样"。
> 适用：玩法「谁最可能」（`packId=most-likely`, `type=vote`）一个库重做。
> 已定调：**不分版**（不做一男一女/多男多女/一男多女三库）；**尺度全开放**，由主持人用顶部 `LevelDots`（L1–L5）实时把控。
> 语言：本期**只出中文**，英文待中文定稿后统一补。

---

## 0. 为什么重做

- 现役 50 题自 V1.3 SSOT 导入后**从未改过**（`git log` 仅一次导入提交）。
- 其中 L2–L4 共 42 题几乎全是"异性指向"的**模糊印象题**（"谁最容易让异性注意到""谁越聊越有意思"）：不产瓜、不好笑、还无聊。
- 业界（TOZ / Teen Vogue / Glamour / MomJunction 等）"谁最可能"的通用核心是**吃瓜**——原话："挑那些能把群里'案底'翻出来的问题"。现役恰好把这块做没了。

**核心目标**：把 50 题从"印象打分"改成"**吃瓜爆料**"，并让每一档对应一个明确尺度。

---

## 1. 为什么不分版（对照大冒险，一次说清）

|            | 大冒险              | 谁最可能                                                              |
| ---------- | ------------------- | --------------------------------------------------------------------- |
| 题的本质   | "谁对谁做**动作**"  | "大家一起**指谁**最可能……"                                            |
| 谁来指定   | 题面必须指定对象    | **群体投票**，天生自带"共决"                                          |
| 与性别结构 | 强相关 → 必须分三版 | **无关** → 不必分版                                                   |
| 业界分类轴 | —                   | 尺度/关系（funny / friends / couples / NSFW），**无人按男女比例分版** |

结论：大冒险分版是机制要求；谁最可能分版是伪需求。**一库 + 档位**即可覆盖所有局。

---

## 2. 判定尺（每张卡落地前自检，全过才收）

1. **能翻案底**：答完能说出"谁做过什么/谁是什么人"，不是纯印象。
2. **票会分**：不能全桌都指同一个人；要有争议、能追问"为什么"。
3. **性别中性**：任何男女比例都能玩（这是"不分版"的前提）。
4. **不聚焦唯一异性**：避开"谁最可能被异性搭讪"这类在 1 男 N 女局反复指向同一人的题。
5. **善意**：被指的人能笑着接，不揭真疤、不逼隐私。
6. **酒吧可玩**：一句话就懂，不喊话、不表演。

## 3. 档位定义（主持人的尺度旋钮）

| 档  | 定位                              | 典型局              | 尺度 |
| --- | --------------------------------- | ------------------- | ---- |
| L1  | 轻吃瓜：拆人设（装/反差）         | 朋友局开场          | 安全 |
| L2  | 朋友吃瓜 / 黑历史（真案底）       | 朋友局主场          | 安全 |
| L3  | 感情吃瓜（早恋/暗恋/前任/同时聊） | 朋友局 + 暧昧局通用 | 轻   |
| L4  | 暧昧升温                          | 暧昧局              | 中   |
| L5  | 成人劲爆                          | 暧昧局 / 18+        | 高   |

> **从 L1 到 L5 是一条"吃瓜由浅到深"的线**，L1 不是"无伤大雅的破冰凑数"，而是"拆人设"的轻吃瓜——安全，但仍要能指人、能追问理由。
> **朋友局 ≈ 玩到 L1–L3；暧昧局 ≈ 一路到 L5。** 切档 = 点顶栏 `LevelDots`，主持人在现场决定放到哪一档，不需要库里做"开关"。

## 4. 各档题面特征与示例题（示意）

### L1 轻吃瓜：拆人设（安全，但要好笑）

特征：人设反差——谁"表面一套、背后一套"。不揭真疤，但仍是吐槽式爆料，能指人、能追问。

- 谁最可能是全桌最会装的？
- 谁最可能表面大大咧咧、其实最记仇？
- 谁最可能嘴上说"无所谓"，心里最在意？
- 谁最可能人前自律、人后放飞？
- 谁最可能朋友圈精修、线下原形毕露？
- 谁最可能嘴上说不八卦、耳朵最灵？
- 谁最可能是"生人面前社恐、熟人面前社牛"？
- 谁最可能是全桌最慢热、熟了之后最疯的？

### L2 朋友吃瓜（黑历史）

特征：朋友圈"案底"、借钱、八卦、偷偷做的事。

- 谁最可能跟朋友借钱，然后假装忘了还？
- 谁最可能当面不说、背后吐槽？
- 谁最可能手机里存着全桌最多的黑照？
- 谁最可能是群里唯一知道所有秘密的人？
- 谁最可能发了消息又秒撤回？
- 谁最可能为了不参加聚会而装病？
- 谁最可能偷偷翻过别人的朋友圈翻到三年前？
- 谁最可能在同一晚把同一个故事讲两遍还浑然不觉？

### L3 感情吃瓜（朋友局 + 暧昧局通用，最吃瓜一档）

特征：早恋、暗恋、前任、同时暧昧——你点名的方向。

- 谁最可能最早早恋？
- 谁最可能第一个脱单？
- 谁最可能同时和两个人暧昧？
- 谁最可能偷偷翻前任的动态？
- 谁最可能在喜欢的人面前秒变安静？
- 谁最可能收到过最多次表白？
- 谁最可能嘴上说"不想恋爱"，其实心里有人？
- 谁最可能暗恋过在座的人（不用说是谁）？
- 谁最可能是那种"嘴上不在意、回消息最快"的？
- 谁最可能散场后还在想今晚某个人？

### L4 暧昧升温（暧昧局）

特征：心动、暧昧、想亲近，带一点试探。

- 谁最可能今晚就有了"想再聊一次"的对象？
- 谁最可能在气氛刚好时先动心？
- 谁最可能是全桌最会撩、却自己不承认的？
- 谁最可能被一个人认真看着就脸红？
- 谁最可能表面淡定、私下已经想好怎么接话？
- 谁最可能在这种局里最容易对号入座？

### L5 成人劲爆（暧昧局 / 18+）

特征：情史、经历、大胆坦白。用语克制、不露骨（红线见 §5）。

- 谁最可能是全桌恋爱经历最多的？
- 谁最可能有过一段"纯暧昧没在一起"的关系？
- 谁最可能被朋友起哄追问过感情细节？
- 谁最可能嘴上最放得开、其实最保守？
- 谁最可能对前任还留着一点说不清的情绪？
- 谁最可能是全桌嘴上最会、实际最怂的？

> L1–L4 为面向普通朋友/暧昧局的**安全主体**；L5 只做"坦白式吃瓜"，不写露骨性描写，保持可当面念出。

## 5. 字段与数量方案

- **id 前缀**：沿用现役 `PN-MOST-*`，不新增。
- **数量**：建议 **60 题**——L1 10 ／ L2 14 ／ L3 14 ／ L4 12 ／ L5 10。
- **字段**：`contentTags: []`（本轮不设盾牌标签）；`timerSeconds` 全 `null`（投票题无计时）。
- **instruction**：各档建议统一为"倒数三秒，一起指；被指最多的人说一句为什么"。
- **红线**：不写露骨性描写、不写强迫、不点名羞辱；L5 一律"愿意说才说，可跳过"。
- **语言**：本期只出中文，英文待中文定稿后统一补。
