# 大冒险 · 三版差异化设计稿（过稿用）

> 状态：设计稿，未落地。**现役 `content/punishment/*.ts` 一律不改**，本稿只描述"应该长成什么样"。
> 适用：`大冒险` 一个玩法，拆成三版题库 —— 一男一女（`couple`）／多男多女（`normal`）／一男多女（`oneMany`）。
> 语言：本期**只出中文**；英文待中文定稿后统一补。
> 环境：酒吧现场嘈杂 —— 题卡**避免"大声喊话／表演／吸引全场注意"**，优先近距离、低声、两人或小圈即可完成的动作。

---

## 出题铁律（10 条，全部卡按此审）

1. **五档必须真递进**：L1 认输嘴炮（零距离）→ L2 首次接触 → L3 暧昧靠近 → L4 亲密 → L5 高亲密；高档不得出现低档的"纯说话"卡（如 L3 说感谢、L4 交换回忆）。
2. **站在"输家"身上出题**：输家是执行者/主动方——赢家指定 → **你**去做 → 喝一口；不得让输家指挥赢家（如要赢家夸自己）。
3. **惩罚里藏"撮合"**："赢家指定一位异性"＝把输家推给指定的人；**指定错也是惩罚**。
4. **必须真互动**：不许自说自话/自言自语式自饮（如自言自语"买回面子"、只举杯看眼睛、敲桌子）。
5. **酒吧环境硬约束**：不许大声、表演、吸引全场注意；不许需要"同时说、听清对方"的题（吵，听不见）。改用近距离、低声、肢体、眼神。
6. **统一收尾**：每张卡动作做完后"**喝一小口**"（主动跳过不罚喝）。
7. **对象指向按局型**：一男一女＝只有"对方"；多男多女＝必须"指定／选一位异性"；一男多女＝男生为焦点、由他在女生中选。
8. **隔壁桌是"分档开关"**：仅多男多女 **L2** 可用（撮合错＝增加互动）；**L3 起禁用**（进 L3＝锁定桌内撮合对象，只推进这两人）。
9. **题面短而具体**：能一个词/一个动作说清就别绕（"说出一个瞬间"→"用一个词夸对方"）。
10. **宁缺毋滥**：题库够用即止，**不设固定张数**；无聊、没互动、不符合以上任何一条的卡一律删掉，绝不为凑数保留（题目少没关系，无聊/没意思才是问题）。

## 0. 为什么现在必须重做（问题定义）

现役三库经逐字比对几乎同质：

- `oneMany.ts`（一男多女）与 `challenges.ts`（多男多女）**逐字完全相同**（55 题 0 差异）；
- `couple.ts`（一男一女）与上面两库**仅最末 11 张 L5 不同**，L1–L4 一模一样。

结果："分三种"只改了菜单名和 11 张 L5 的措辞，**场景差异没有落到题面**。玩家换了性别结构，玩到的还是同一副牌，体验不变。

**本稿要解决的核心问题**：人数与性别结构决定"**谁对谁做什么**"。同一句题面在三种局里的落地效果完全不同，所以三库必须在"**对象指向、指定机制、命题重点**"上真正分化。

## 1. 出题前先问两句（统一判定尺）

每张题卡落地前，先回答两个问题，答案直接决定措辞：

1. **"对方"是谁？** —— 唯一对手（不用指定）／众多异性中的某一位（必须指定）／一群同性（指向群体）。
2. **"指定"由谁做、能不能拒绝？** —— 单人局无需指定；多人局必须"赢家或自己指定＋可跳过"；失衡局用"群体共决＋自愿"。

三库的差异，本质就是这两问的答案不同。

### 1.1 环境约束（新增，优先级同判定尺）

酒吧环境吵，**"表演类"动作全部不合适**：凡是要大声、要被全场盯着看、要"站出来演一段"的题，一律不采纳。替代方向：

- 用**近距离低声**动作替代喊话（凑近说、耳语、碰杯时对视）；
- 用**双人/小圈**动作替代"面向全场"（和身边一人、和指名的一个人完成）；
- 用**肢体/眼神**替代语言表演（碰杯、击掌、对视、握手）；
- 集体动作改成**轮流通关**而非齐声喊（每人一个小动作，不用一起出声）。

## 2. 三库定位对比（一表看清）

| 维度       | 一男一女 `couple`                 | 多男多女 `normal`                    | 一男多女 `oneMany`                                                |
| ---------- | --------------------------------- | ------------------------------------ | ----------------------------------------------------------------- |
| 适用局     | 2 人（1 男 1 女）                 | 多人，男女都不止一个                 | 1 男 + 多个女（少数性别）                                         |
| 异性数量   | 唯一                              | 多个                                 | 女多男少（男生稀缺）                                              |
| 核心目标   | 把**唯一这一对**往暧昧/亲密推     | 全场互动＋**公平分配＋防强行配对**   | 男生为**焦点/男主角**，**由他在女生中选择**；女生围绕他争取被选中 |
| 对象措辞   | "**对方／你俩**"                  | "**赢家指定一位异性／自己选一位**"   | 男生分支="全场女生"；女生分支="唯一的男生"                        |
| 指定机制   | **不用指定**（只有一个人）        | **必须指定**（否则落不了地）         | **由男生指定/选择女生**（女输时男生裁决）                         |
| 安全阀     | 双向同意＋可跳过                  | 指定＋可换人＋可跳过                 | 男生选择＋双方同意＋可拒绝／可跳过                                |
| 主要互动   | 对视、牵手、贴身、接吻            | 碰杯、握手、按摩、拥抱、接吻         | 选人碰杯/对视/握手、女输向男生争取、二选一时男生裁决              |
| 忌讳／红线 | 无第三者可互动，别写"全桌/隔壁桌" | 别把输家强配给某个具体的人           | 别让唯一的男生被强制与某位女生单点亲密；别让女生"排队"            |
| 命题基调   | 约会感、连续升温                  | 公平、谁都能上场、以肢体动作代替喊话 | "选妃/被竞争"轻喜剧、男生焦点（**A2**）                           |

## 3. 分档设计（L1–L5 每档"该长什么样"）

三库**保留同档位阶梯**（现役 12／8／10／14／11＝55 题），但每档内容按上表分化。

### 3.1 一男一女 `couple`

| 档  | 定位       | 题面特征                                                                 |
| --- | ---------- | ------------------------------------------------------------------------ |
| L1  | 认输＋自嘲 | 面向**对方**低声说一句/敬酒（**不喊、不面向全桌**）；不出现"全桌/隔壁桌" |
| L2  | 轻度接触   | 与对方碰杯、握手、靠肩；全程双向                                         |
| L3  | 暧昧       | 对视、牵手、贴耳说话；引导两人关系升温                                   |
| L4  | 亲密       | 拥抱、贴面、壁咚；双方同意                                               |
| L5  | 最高亲密   | 接吻、额头相抵；**明确"双方同意＋可跳过"**                               |

### 3.2 多男多女 `normal`

| 档  | 定位           | 题面特征                                                      |
| --- | -------------- | ------------------------------------------------------------- |
| L1  | 全场破冰       | 与全桌/邻座**碰杯、递杯**等无需出声的集体动作；**不指定个体** |
| L2  | 引入指定       | "赢家指定一位异性"或"自己选一位"轻接触（碰杯、握手）          |
| L3  | 指定异性轻接触 | 对视、整理衣领、按摩（对方可拒绝）                            |
| L4  | 指定异性亲密   | 拥抱、贴耳（**可换人、可跳过**）                              |
| L5  | 最高亲密       | 由赢家指定＋双方同意；不同意可换人或喝酒代替                  |

### 3.3 一男多女 `oneMany`

| 档  | 定位                   | 题面特征                                                                                               |
| --- | ---------------------- | ------------------------------------------------------------------------------------------------------ |
| L1  | 男输选人／女输争取     | **男输**：从女生里选一位碰杯、添酒、请整理衣领等；**女输**：向男生说一句想被他记住的话                 |
| L2  | 选址做轻接触           | **男输**：选一位女生握手、交杯、击掌；**女输**：向男生递杯、说一句争取的话（可比出胜负由男生裁决）     |
| L3  | 选址做暧昧             | **男输**：选一位女生对视、贴耳、牵手；**女输**：向男生说想和他做的事／参与"多选一"由男生选             |
| L4  | 选址做亲密（可拒）     | **男输**：选一位女生拥抱、贴面（对方可拒绝）；**女输**：向男生争取，由他在你和另一位女生中选           |
| L5  | 最高亲密（选择＋同意） | **男输**：选一位女生接吻等（双方同意、可换人）；**女输**：向男生说"选我，由你决定"。亲密项一律可选可跳 |

> **机制提示**：一张卡可同时写"男输→…；女输→…"两个分支（现役已有"男生…女生…"同桌一张卡的写法），不需要 App 判断输家性别。

## 4. 示例题（示意，仅中文；标注与原库差异）

### 4.1 一男一女 `couple`

- L1 `看着对方，低声说：“这一轮我甘拜下风。”` —— 原库是面向全桌"大哥/姐姐"，改为**直指对方、且不喊**。
- L1 `向对方举起杯子，说：“这杯敬赢家。”然后喝一小口。`
- L2 `和对方碰杯，碰杯全过程必须看着对方的眼睛。`
- L3 `和对方勾住小指，对视 10 秒。`（`timerSeconds: 10`）
- L4 `和对方面对面拥抱 15 秒，谁先松手谁喝一口。`（`timerSeconds: 15`）
- L5 `和对方接吻 10 秒（双方同意；不同意可用喝一口代替）。`（`timerSeconds: 10`）

### 4.2 多男多女 `normal`

- L1 `和你左右两边的人各碰一次杯（不用说话）。`
- L2 `由赢家指定一位异性，和你碰杯。`（**出现"指定"**）
- L3 `赢家指定一位异性，你和对方对视 10 秒。`（`timerSeconds: 10`）
- L4 `赢家指定一位异性，和对方拥抱 15 秒（对方可拒绝，拒绝不处罚）。`（`timerSeconds: 15`）
- L5 `赢家指定一位异性，双方同意后接吻 10 秒（不同意可换人或喝一口代替）。`（`timerSeconds: 10`）

### 4.3 一男多女 `oneMany`

- L1 `男输：从全场女生里选一位，和 TA 碰一次杯；女输：向唯一的男生举杯，说一句“这杯敬你”。`
- L2 `男输：选一位女生，和 TA 握手 3 秒后松开；女输：和另一位女生一起向男生伸手，由男生选一只握住。`（`timerSeconds: 3`）
- L3 `男输：选一位女生，和 TA 勾住小指对视 10 秒；女输：向男生说一句“选我，我陪你做这个动作”。`（`timerSeconds: 10`）
- L4 `男输：选一位女生，和 TA 拥抱 15 秒（对方可拒绝，拒绝不处罚）；女输：向男生说一句“选中我，我答应你一个小要求”。`（`timerSeconds: 15`）
- L5 `男输：选一位女生，双方同意后接吻 10 秒（不同意可换人或喝一口代替）；女输：向男生说一句“选我，但由你决定”。`（**选择＋同意，可跳**）

## 5. 字段与数量方案（建议沿用现役结构，便于日后整库替换）

- **id 前缀**：`couple=DA-DUO`、`normal=DA`、`oneMany=DA-OMF`（沿用现役，不新增）。
- **数量（已定，冻结目标）**：三库各 **55 题**，档位 **L1 12 ／ L2 8 ／ L3 10 ／ L4 14 ／ L5 11**。内容定稿后按下表补齐差额（当前为编辑过程值）。
- **字段**：`contentTags: []`（本轮不设盾牌标签）；`timerSeconds` 仅在对视/拥抱/接吻类填具体秒数，其余 `null`。
- **语言**：本期**只出中文**，英文待中文定稿后统一补（避免中文反复改导致英文空转）。
- **红线**：不写强迫灌酒、非自愿脱衣、露骨性描写；亲密题一律带"双方同意＋可跳过"。
- **饮用收尾**：每张卡在动作完成后**统一以"喝一小口"收尾**（主动跳过者不罚喝）。
- **隔壁桌**：仅"多男多女"的 **L2** 可用（"指定／选一位异性"可含隔壁桌，撮合错＝增加互动/惩罚）；**L3 起不可用**（进入 L3＝主持人已锁定桌内撮合对象，只推进这两人，不再含隔壁桌）。一男多女**限本桌**；一男一女无此概念。
