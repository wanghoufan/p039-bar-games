# 内容质量审查判定口径（Phase A｜全 7 批共用，务必逐字遵守）

你在审 Party Night V2 当前实际运行的 350 张主线题卡中的一部分。目标不是挑刺，而是**如实判定每张题玩完之后，参与者到底多知道了这个人什么**。

用户真机试玩后的原话（这是本轮审查的起因，必须拿它当标尺）：
> 整体非常无聊，很多题虽然形式上在互动，但玩完之后并没有真正增加彼此了解；缺少兴趣爱好、生活方式、恋爱观、择偶观、亲密/性观念、小癖好等真正有信息增量的内容。

## 你要输出的每一行（一行一张卡，字段顺序固定）

严格输出 JSON Lines：**一行一个 JSON 对象，不要数组、不要 Markdown 代码块围栏、不要任何解释文字**。行数必须与输入行数完全一致，cardId 与顺序必须与输入完全一致，不要漏、不要多、不要改写题面。

每行字段：

1. cardId（照抄输入）
2. gameType（照抄）
3. text（照抄输入原文，一个字都不要改）
4. semanticType — 真人语义类型，**只能取下面 6 个值之一**
5. topic — 信息主题，**只能取下面 10 个值之一**
6. infoGain — 信息增量，**只能取 高 / 中 / 低 / 0**
7. learned — 玩完后新知道什么，一句大白话，必须具体到「知道了谁的什么」
8. promotesUnderstanding — 是 / 弱 / 否
9. duplicateGroup — 同质重复组标签或 "-"
10. verdict — 保留 / 改写候选 / 删除候选

## 1. semanticType 判定（只能选一个，以主要动作与信息落点为准）

- `自我披露`：主要让**说话的人讲自己**（自己的经历、偏好、感受、过去）。
- `相互了解`：主要产出**关于对方/彼此的稳定个人信息**，两个人真的交换了可复述的事实。
- `现场评价/猜测`：对在场某个人**下评价、猜心思、投票、排名、指认**。哪怕形式上是"让某人对某人说话"，只要落点是"大家觉得这人怎么样"而不是"这人有什么个人信息"，就算这一类。
- `行动互动`：内容是一个动作（碰、换位、递东西、走过去、闭眼…），动作本身就是全部内容。
- `暧昧推进`：明确朝男女关系升温（表态、择偶、亲密试探、表白、加码）。
- `纯看戏/低信息`：群体起哄、喊口号、纯热闹、跟任何具体人物信息都挂不上。

## 2. topic 判定（只能选一个，以"答完知道了什么"为准，不是以题面字面为准）

- `兴趣爱好`：具体的爱好、兴趣、技能、玩什么（游戏/运动/乐器/旅行方式…）。
- `生活方式`：作息、居住、工作节奏、饮食、消费、健身作息、日常习惯。
- `性格/习惯/小癖好`：性格倾向、说话方式、具体小癖好、隐藏技能、反差萌。
- `择偶偏好/吸引力`：喜欢什么类型、什么样的男生/女生有魅力、择偶条件。
- `恋爱观`：对恋爱的态度、在一起意味着什么、恋爱里的规则与红线。
- `亲密/性观念`：亲密尺度、身体距离边界、暧昧容忍度、亲密相关态度。
- `边界/吃醋/异性朋友/前任`：边界感、吃醋、异性朋友、前任、占有欲。
- `人生价值/未来`： goals、人生优先级、五年十年打算、理想生活。
- `现场化学反应`：题目考的是"此刻这桌人之间发生了什么"，属于本局临时状态，不构成稳定个人信息。
- `无明确人物信息增量`：玩完得不到任何关于具体某个人的信息。

## 3. infoGain 判定（这是本轮最关键的列，请严格）

- `高`：答完你就得到**一条关于这个人的、具体的、能复述的、以后还记得的稳定事实**。例："他每周三固定去打羽毛球"、"她理想中的恋爱是先在一起三年再考虑结婚"、"他不吃香菜"、"她存钱是为了去冰岛看极光"。
- `中`：得到**一条半稳定的印象**，能复述但不算确定事实。例："他有点毒舌"、"她今晚情绪不太高"、"他比看起来更会照顾人"。
- `低`：只得到**一次性的现场反应或情绪**，换个局就作废，讲不出这人的任何属性。例："他被夸会笑"、"他起哄最积极"。
- `0`：**完全不产生关于人的信息**。纯群体起哄、纯道具动作、纯猜谁最X且无下文、纯复述题面、纯喊口号。

## 4. promotedUnderstanding 判定（是 / 弱 / 否）

- `是`：明确让某人/双方获得对方的个人信息。
- `弱`：有一点点但不稳。
- `否`：完全不产生人物认知。

## 5. verdict 判定（保留 / 改写候选 / 删除候选）

- `保留`：infoGain 为 高 或 中，且主题落在用户点名的缺口主题上（兴趣爱好 / 生活方式 / 性格习惯小癖好 / 择偶偏好 / 恋爱观 / 亲密观念 / 边界前任 / 人生价值未来），或属于必要的现场调剂。
- `改写候选`：infoGain 为 低，骨架能救（同质化、主题可换、对象可换）。
- `删除候选`：infoGain 为 0，或纯凑数、纯重复、跟人物信息完全无关。

## 严禁犯的两个错（本轮专门要抓的就是这个）

1. **严禁把「对在场某个人发表评价/猜测」自动算成「相互了解」。**
   像「谁最容易被异性搭讪？」「TA 给你的第一印象是什么？」「谁最有吸引力？」「谁最可能让人想继续聊？」这类，形式上有互动，但玩完没有新增稳定人物信息 → 一律判 `现场评价/猜测`，infoGain 只能是 `低` 或 `0`。
2. **严禁因为题面"看起来像互动"就给高增量。** 增量只看你答完之后脑子里留下了什么关于这个人的东西。

## 特别提示（针对这几类，请重点判定）
- 大量出现的「第一印象 / 注意谁 / 谁更有意思 / 谁想继续聊 / 谁最想再约」这一族：几乎都是 `现场评价/猜测` + 低增量 + 重复组。
- 「我从来没有…」族：注意区分——逼当事人讲**自己具体经历**的是好题（自我披露，可能高增量）；只是喊一句"有人吗"再起哄的是低增量。
- 「二选一」族：选项本身是关于**自己**的偏好还是关于**别人**的评价？前者偏好类可中增量，后者多为低。
- 「指认/指人」族：动作本身是内容，多为 `行动互动` 或 `现场评价/猜测`。
- 「默契/chemistry」族：看它是真的在核对两个人的真实重合，还是只是让大家热闹一下。
